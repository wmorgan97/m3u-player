# TiviMate Parity Matrix (NVIDIA Shield app)

**What this compares.** TiviMate, a commercial Android TV IPTV player, is the reference. The "Existing behaviour" column comes only from the code; file references point to `android/app/src/main/java/com/wmorgan97/m3uplayer/` unless they start with `server/` or `js/`.

**Reference behaviour.** This comes from general product knowledge, not from TiviMate itself. Anything marked **(unverified)** needs checking against a real TiviMate install before it becomes an acceptance criterion.

**Status column.** The values are Inspected, Defect confirmed, Implemented (not verified) and Verified on Shield. "Verified on Shield" appears only where a measurement exists:

| Screen | gfxinfo 90th-percentile frame time |
|---|---|
| Home | 18 ms |
| Movies | 17 ms |
| Series | 5 ms |
| Live list | 13 ms |
| Guide | 29–34 ms |
| Zap to picture | about 0.65 s |

**Priorities:**
- **P0:** wrong or unsafe behaviour.
- **P1:** core TiviMate flow missing or broken.
- **P2:** noticeable gap.
- **P3:** polish.
